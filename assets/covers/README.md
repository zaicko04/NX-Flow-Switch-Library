# Portadas personales

Carga aquí imágenes JPG, PNG o WebP autorizadas. Después asigna una ruta desde data/covers.json:

- Ejemplo: assets/covers/super-mario-64.webp
- En data/covers.json: "Nintendo 64|Super Mario 64": "assets/covers/super-mario-64.webp"

El sitio preserva la portada incluso cuando se vuelva a generar el catálogo.
