# Colecciones personales

Cada archivo JSON representa una consola. Por ejemplo:

- `nintendo/n64.json` → Nintendo 64
- `playstation/ps2.json` → PlayStation 2
- `sega/dreamcast.json` → Dreamcast

Formato:
```json
{
  "items": [
    {
      "title": "Nombre de tu port",
      "url": "https://github.com/autor/repositorio",
      "version": "1.0",
      "author": "Autor",
      "description": "Requiere los archivos originales del juego"
    }
  ]
}
```

No coloques ROMs, ISOs ni archivos de juegos comerciales sin permiso. El importador agrupa las entradas por consola.
